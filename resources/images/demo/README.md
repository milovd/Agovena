# Official demo imagery

The six catalog assets in this directory are original Agovena demo assets generated for this repository.

They follow the approved reference direction:

- photorealistic commercial photography;
- natural workplace, packing and event contexts;
- cobalt-blue Agovena accents;
- real materials, daylight and shallow depth of field;
- no provider credentials, real endpoints or customer data;
- no external network download is required when seeding the demo.

The explicit `agovena:seed-demo --force` command copies these assets into `storage/app/public/demo/`. The normal application boot and standard database seeding do not load them.
