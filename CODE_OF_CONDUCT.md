# Code of Conduct

## Our pledge

We want Agovena to be a respectful place for anyone interested in the project: users, contributors, and maintainers.

## Expected behavior

- Be patient and constructive
- Assume good intent
- Disagree on ideas, not people
- Respect different experience levels and backgrounds

## Unacceptable behavior

- Harassment, insults, or personal attacks
- Trolling, baiting, or derailing discussions
- Publishing private information without permission
- Anything that would be unreasonable in a professional setting

## Enforcement

Maintainers may remove comments, close issues/PRs, or ban contributors who break this code of conduct.

If you see a problem, contact the maintainers privately (do not open a public issue that escalates harm). Prefer GitHub private channels when available.
