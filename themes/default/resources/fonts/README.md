# DM Sans

Original, unmodified DM Sans WOFF2 files, distributed under the SIL Open Font
License 1.1. See `OFL.txt` for copyright and license terms.

The Default Theme hosts these files itself so Admin, storefront and checkout
render without contacting a third-party font service. Normal and italic faces
cover weights 400 through 700, with Latin and Latin Extended subsets. The shared
font-face stylesheet is `../css/settings/_fonts.css`; Vite fingerprints the assets.

Source: Google Fonts DM Sans v17, retrieved 2026-10-20 using the Google Fonts CSS
API for `DM Sans:ital,opsz,wght@0,9..40,400..700;1,9..40,400..700`.

Original files:

- Normal Latin: `https://fonts.gstatic.com/s/dmsans/v17/rP2Hp2ywxg089UriCZOIHQ.woff2`
- Normal Latin Extended: `https://fonts.gstatic.com/s/dmsans/v17/rP2Hp2ywxg089UriCZ2IHSeH.woff2`
- Italic Latin: `https://fonts.gstatic.com/s/dmsans/v17/rP2Fp2ywxg089UriCZa4Hz-D.woff2`
- Italic Latin Extended: `https://fonts.gstatic.com/s/dmsans/v17/rP2Fp2ywxg089UriCZa4ET-DNl0.woff2`
- License source: `https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt`

When updating, preserve the upstream license, normal and italic faces, subset
coverage and weight range. Run the local-font regression tests, rebuild assets,
and verify font loading from the same origin in a real browser.
